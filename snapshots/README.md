# Saved snapshots

The Concert Passport shows these files instantly instead of running a slow live scan:

- `rare_songs.json`: Rarest Songs You've Heard
- `artist_popularity.json`: Big Names & Hidden Gems

To make or update one, run the scan in the app, click **💾 Save as snapshot**, then upload
the downloaded file here (Add file → Upload files). The scan buttons still run a fresh live
scan any time. Delete a file to go back to live-only for that section.
